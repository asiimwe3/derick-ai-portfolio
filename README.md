# derick-ai-portfolio

👤 Derick AI Portfolio — personal portfolio website showcasing projects, skills, and AI-powered interactive features. Static HTML/CSS/JS.

## 🚀 Features

- Modern, responsive UI design
- Optimized performance and fast load times
- Cross-platform compatibility
- Clean, maintainable codebase
- Production-ready architecture

| Category | Technology |
|----------|-----------|
| Language | HTML5 |

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/asiimwe3/derick-ai-portfolio.git
cd derick-ai-portfolio

# Install dependencies
npm install  # if using a build tool

# Start development
Open index.html in browser
```

## 🔧 Build

```bash
Deploy to GitHub Pages / Vercel
```
